# Jamb-replicate

A frontend-focused project replicating JAMB (Joint Admissions and Matriculation Board) website design and functionality.

## 🛠️ Tech Stack

- **HTML** (52.7%) - Structure and markup
- **SCSS** (26.3%) - Advanced styling
- **CSS** (19.7%) - Base styling
- **JavaScript** (1.3%) - Minimal interactivity

## 📋 Features

- Clean, responsive design
- Static site structure
- Modern CSS styling with SCSS preprocessing
- Lightweight and fast-loading

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Explore the project structure
